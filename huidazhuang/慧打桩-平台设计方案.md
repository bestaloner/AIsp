## 1. 产品概述

### 1.1 产品定位

**慧打桩**是面向建筑桩基工程行业的全流程数字化管理平台。系统以**施工图纸**为数据源头，通过图纸解析自动提取桩点数据，围绕"分区分层→任务计划→任务下发→施工孪生→数据填报→报告生成"的核心链条，实现桩基工程从图纸到交付的全程数字化。

### 1.2 核心价值

| 维度 | 传统方式 | 慧打桩 |
|------|---------|--------|
| 数据来源 | 人工读图录入 | DWG图纸自动解析 |
| 任务管理 | 纸质派工单 | Web→平板数字化下发 |
| 施工管控 | 人工巡检 | 数字孪生+实时填报 |
| 资料归档 | 手动整理 | 填报后自动生成报告 |

### 1.3 用户角色

| 角色 | 使用端 | 核心场景 |
|------|--------|---------|
| 项目经理 | Web端 | 项目管理、图纸导入、计划制定、进度总览 |
| 施工员/班组 | 平板（移动端） | 接收任务、填报施工数据 |
| 监理 | Web端 | 查看报告、质量验收 |
| 设备管理员 | Web端 | 设备台账、维保管理 |

### 1.4 核心数据单元

系统以 **"桩点"** 为最小数据单元。每个桩点包含：
- **标识信息**：桩点ID（CAD图元ID）、桩编号
- **空间信息**：所属分区、图纸X/Y坐标、高程
- **物理属性**：桩长、桩径、体积、混凝土强度
- **施工属性**：施工工法、承载性质、持力层性质
- **状态信息**：未开始 / 进行中 / 已完成

## 2. 核心业务流程

### 2.1 主干流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ ① 图纸   │───▶│ ② 分区   │───▶│ ③ 任务   │───▶│ ④ 下发   │───▶│ ⑤ 施工   │
│   导入   │    │   分层   │    │   计划   │    │   执行   │    │   填报   │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
                                                                     │
                                                                     ▼
                                                              ┌──────────┐
                                                              │ ⑥ 报告   │
                                                              │   生成   │
                                                              └──────────┘
```

**① 图纸导入与解析**
- 上传 DWG 施工图纸
- 系统自动解析桩点图层，提取：桩点ID（CAD图元ID）、桩编号、图纸X/Y坐标、桩长
- 解析结果生成"桩点信息列表"

**② 分区分层**
- 在"设置→施工分区"中创建施工分区（A区-基坑支护、B区-主体工程桩、C区-围护桩等）
- 每个分区关联一张启用的图纸
- 桩点按分区归类，后续任务计划以分区为维度组织

**③ 任务计划**（需求待确认）
- 基于分区和桩点数据创建日计划
- 任务类型：打桩任务 / 监测任务 / 浇筑任务
- 日计划→作业下发（Web→平板）

**④ 任务下发**（需求待确认）
- 选择计划中的桩点，分配至具体设备
- 下发至平板的施工班组
- 任务状态随填报进度自动变化

**⑤ 施工填报**（需求待确认）
- 桩机班组按工艺流程逐步填报实际参数
- 支持手动填报/智能设备自动获取（成孔检测数据）
- 数字孪生展示实时施工状态

**⑥ 报告生成**
- 填报完成后，系统按桩点自动生成施工报告
- 支持10种标准报告类型（见[资料管理](#8-资料管理)）
- 支持筛选、汇总、导出

### 2.2 辅助流程

- **设备管理**：设备台账→进场/退场→维保跟踪
- **勘察数据**：非必须增项，客户按需录入桩点勘察信息
- **图形图像**：按分部工程上传现场照片

## 5. 图纸管理

### 5.1 定位

图纸是整个系统的**数据源头**。桩点的标识、坐标、物理属性均来源于DWG施工图纸的自动解析。

### 5.2 子模块结构

```
📐 图纸
├── 📐 图纸管理（主Tab）
└── 📍 桩点信息（次Tab）
```

### 5.3 图纸管理 — 功能详述

#### 5.3.1 图纸列表

| 字段 | 说明 |
|------|------|
| 序号 | 自增 |
| 图纸名称 | 上传时命名 |
| 图纸类型 | 桩位平面图 / 支护结构图 / 基础平面图 / 其他 |
| 上传时间 | 导入时间戳 |
| 解析状态 | 解析中 🔴 / 已完成 🟢 / 已废弃 ⚫ |
| 关联桩点数 | 解析完成后显示提取的桩点数量 |
| 启用 | 单选启用（同一时间仅一张图纸启用） |
| 操作 | 预览 / 重新解析 / 废弃(恢复) / 下载 |

#### 5.3.2 核心业务规则

**① 导入图纸**
- 支持格式：DWG
- 导入后系统自动启动解析任务
- 解析状态显示"解析中"，完成后更新为"已完成"并显示桩点数

**② 图纸解析**
- 自动提取桩点图层的图元信息
- 至少提取：桩点ID（CAD图元ID）、桩编号、图纸X坐标、图纸Y坐标、桩长
- 解析结果自动写入"桩点信息"列表

**③ 启用规则（关键）**
- 同一时间**仅可启用一张图纸**
- 点击另一张图纸的"启用"时，自动取消当前启用
- 启用图纸决定了：2D桩位平面图的数据源 + 桩点信息列表的数据源
- 启用图纸不可废弃，需先启用其他图纸

**④ 废弃/恢复**
- 废弃为软删除，勾选"显示已废弃"可查看并恢复
- 已启用的图纸不可废弃

**⑤ 下载**
- 下载原始DWG文件

#### 5.3.3 图纸启用交互

```
图纸A ✅ 启用中 ────┐
                    │ 点击图纸B的"启用"
图纸B ○ ───────────┘
                    ↓
图纸A ○            （自动取消启用）
图纸B ✅ 启用中     （新启用）
                    ↓
2D平面图数据切换    （自动重绘）
桩点信息列表切换    （自动刷新）
```

- **补充来源**：Excel批量导入（用于手动补充或变更数据）

| 9 | 施工工法 | 图纸解析 | ✅ |
| 10 | 承载性质 | 图纸解析 | ✅ |

## 6. 任务管理

> ⚠️ **状态：需求待客户确认。** 当前原型以空状态占位展示，保证导航连贯性。

### 6.1 规划中的功能

```
📋 任务
├── 施工计划
│   ├── 总计划（先隐藏）
│   ├── 日计划列表
│   ├── 新增日计划（按分区选择桩点 + 日期）
│   ├── 变更计划
│   └── 作业下发（Web → 平板）
├── 完成总览
│   └── 按日期显示每日完成数量和桩点明细
└── 任务类型（规划）
    ├── 打桩任务
    ├── 监测任务
    └── 浇筑任务
```

### 6.2 关键设计思路

- **日计划**：以"分区 + 日期"为维度，从桩点列表中勾选当日计划施工的桩点
- **三种任务类型**：打桩（成孔+浇筑）/ 监测（成孔检测）/ 浇筑（混凝土灌注）
- **作业下发**：将日计划中的桩点分配至具体设备（旋挖机），下发至平板端
- **完成总览**：按日期汇总每日完成情况（参考安之眸任务总览模式）

│   └── 监测设置（手动/自动获取）
└── 施工记录
    └── 自动从填报数据生成记录列表（20+字段）
```

### 7.2 关键设计思路

- **施工数据孪生**：平板连接桩机后，实时同步施工数据（垂直度、钻进深度、钻杆电流等）到Web端看板
- **成孔检测双模**：有智能监测设备→自动采集；无设备→手动填报
- **钻进速率**：前端实时计算，非服务端存储字段
- **施工记录**：非手动创建，由施工填报数据自动汇总生成

**子Tab切换**（图纸、设置模块）：
```
交互流程：

### 14.4 关键JS数据结构

worldX = (screenX - camera.offsetX) / camera.zoom
