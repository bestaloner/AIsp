一、项目背景与目标

1.1 现状分析

当前 AI 隐患识别系统采用 YOLO（YOLO26s-v2.1，mAP 87.3%）+ VLM（Qwen3.6-27B via vLLM） 双引擎架构，覆盖12类施工安全隐患的检测与分类。在实际运行中，系统大致能识别出隐患，但存在以下问题：

  • 误报率偏高：将正常场景误判为隐患（如普通黄色衣物被判定为反光衣缺失）
  • 漏报风险：部分小目标、遮挡目标、逆光场景无法有效检出
  • 边界案例处理弱：对"部分佩戴安全帽""远处人员""重叠物体"等模糊场景判断不稳定
  • 场景泛化不足：当前模型在特定光照、角度、工地类型下的泛化能力有限

1.2 调优目标

核心目标：通过明确判定规则、建设高质量标注数据集、对 YOLO 和 VLM 进行针对性微调，将12类隐患的综合识别准确率从当前水平提升至可交付的生产级标准。
指标当前值（估算）目标值说明
YOLO mAP@0.5~87%≥ 92%12类均值
YOLO Recall（召回率）~85%≥ 93%减少漏报
YOLO Precision（精确率）~78%≥ 85%减少误报
VLM 复核准确率~82%≥ 90%二次确认
综合准确率（端到端）~75%≥ 88%经人工复核后的最终指标

二、调优范围

2.1 12类隐患清单

本次调优覆盖全部12类施工安全隐患，按物理设施类（5项）与人员行为类（7项）分类管理。

#隐患名称类别典型场景描述当前主要问题
1安全帽未佩戴 行为 施工区域人员头部未佩戴或未正确佩戴安全帽 帽子颜色与背景相近时误判；部分佩戴漏检
2反光衣未穿 行为 施工区域人员未穿着反光安全背心 黄色/橙色普通衣物误报；夜间反光条识别弱
3临边防护缺失 物 楼层边缘、洞口、阳台等临边位置缺少防护栏杆 复杂背景干扰；不同类型护栏识别不一致
4吸烟检测 行为 施工区域内人员吸烟或出现明火烟头 小目标检测困难；与白色细长物体混淆
5人员越界 行为 人员进入危险区域（塔吊回转半径、深基坑警戒区等） 区域边界定义不清晰；需结合场景上下文
6坑边堆载 物 基坑边缘堆放土方、材料、机械等荷载 荷载类型多样，定义边界模糊
7明火检测 行为 施工现场出现明火、火焰或非受控火源 阳光反射、灯光与明火混淆
8散料吊装 物 吊装散料（钢筋、管材等）未使用专用吊具或捆扎不规范 需要组合判断（吊具+物料+捆扎状态）
9人员聚集 行为 危险区域（如脚手架下方、吊装区）多人聚集 需要结合区域定义和人数阈值
10车辆违规 行为 工程车辆超速、逆行、违规停放、未按规定路线行驶 需要时序信息辅助判断
11吊篮作业 物 高处作业吊篮未按要求设置安全绳或超员使用 高空小目标；安全绳细长难检测
12工地围挡封闭 物 工地外围围挡破损、缺失、未完全封闭 围挡形式多样（彩钢板/砖墙/临时围栏），标准不统一

2.2 不在本次调优范围的事项

  • 新增隐患类型的模型训练（仅针对现有12类优化）
  • 平台业务功能变更（不涉及 VisionGuard 业务平台代码修改）
  • 模型架构级别的替换（不更换 YOLO 或 VLM 基础模型架构，仅微调）
  • 实时推理性能优化（本次聚焦精度，推理速度优化另立专项）

三、判定标准

判定标准是数据标注和模型评估的唯一依据。每类隐患定义三种判定结论：正例(Positive) 负例(Negative) 边界(Borderline)

3.1 通用判定规则

判定结论标签通用规则
正例 1 图像/视频中明确存在该类隐患，且具备可辨识的视觉特征。标注人员90%以上把握可确认。
负例 0 图像/视频中明确不存在该类隐患。包括：正常施工场景、已有防护措施到位、与其他隐患类型无关的场景。
边界 -1 无法明确判定是否存在隐患的场景，包括：图像模糊/遮挡严重/光线不足/距离过远/视角不佳。边界样本将单独记录，不直接参与训练，作为难例分析的依据。

3.2 逐类判定细则

以下为每类隐患的具体判定标准。标注人员应在标注前完整阅读并理解。

#1 安全帽未佩戴

判定标准
正例施工区域内，人员头部区域未出现安全帽轮廓（无论颜色）。包括：完全未佩戴、手持安全帽未戴上、佩戴普通帽子/头巾代替。
负例人员头部清晰可见安全帽（任一颜色）；非施工人员（如访客戴白色安全帽在参观通道）；安全帽放置在地面/工具台上（非佩戴状态，不判定为隐患）。
边界头部被遮挡无法判断；人员距离过远（<20px头部高度）；正在摘/戴安全帽的动作瞬间。

#2 反光衣未穿

判定标准
正例施工区域内，人员躯干部位未出现反光安全背心。包括：穿普通外套/T恤/工装但无反光条特征。
负例人员躯干可见反光背心（带明显反光条或荧光色背心）；非施工区人员（办公室/休息区）。
边界反光条被部分遮挡；光线过暗无法辨别反光特征；穿着与反光衣颜色相近的普通衣物但无法确认。

#3 临边防护缺失

判定标准
正例楼层边缘、洞口、阳台、楼梯口等临边位置无防护栏杆或防护栏杆不完整（缺少横杆/立杆间距过大>2m/高度不足<1.2m）。
负例临边位置可见完整防护栏杆（上下两道横杆+立杆+踢脚板）；主体结构施工中尚未形成临边（刚浇筑混凝土，尚未拆模）；已用密目网封闭。
边界防护栏杆被材料遮挡无法判断完整性；远距离拍摄无法看清栏杆细节；正在搭设/拆除防护栏杆过程中。

#4 吸烟检测

判定标准
正例施工区域内，人员手部或嘴部出现点燃的香烟（可见烟头火光或烟雾特征）。
负例未见香烟或烟头；手中持有其他细长物体（笔/工具/钢筋）；指定吸烟区内吸烟（非隐患）。
边界疑似香烟但无法分辨（距离远/像素低）；白色细长物体在手部附近但不能确认；电子烟（无明显火光）。

#5 人员越界

判定标准
正例人员进入明确划定的危险/禁入区域。包括：塔吊回转半径内有人、深基坑底部有人但未登记、已围挡的临边外侧有人。
负例人员在正常施工通道/作业面工作；已授权的巡检人员；危险区域内无人。
边界无法判断具体区域边界（摄像头角度不佳）；人员恰好在区域边界线上。

#6 坑边堆载

📋 法规依据：JGJ 120-2012 §8.1.5, §8.1.6；JGJ 180-2009 §6.3.9；JGJ 311-2013 §8.3.2, §11.2.2；GB 51004-2015 §9.4.6；GB 55003-2021 §7.4.3；GB 55034-2022 §3.5.3

判定标准
正例基坑边缘1.5m范围内（按JGJ 311-2013 §11.2.2条文说明）堆放土方、建筑材料、工程机械等荷载；挖土机械和运输车辆在坑底边线周边与开挖深度相等范围内堆载或行走；坑边荷载超过设计允许值；基坑渗水积水未及时疏导。
负例荷载堆放距离基坑边缘>1.5m且有挡土墙/支护结构防护；基坑周边已做硬化/防渗处理且排水通畅；施工机具在指定平台作业（非基坑边缘）。
边界无法准确判断距离（无参照物）；堆载数量/高度处于临界值附近；排水措施部分失效但未造成明显积水。

#8 散料吊装（更新）

📋 法规依据：闽建办建函[2024]60号 第二条(二)款

判定标准
正例使用承插型盘扣式钢管等材料简易搭设非标料斗进行吊装作业；将钢筋挂成"雨伞状"直接吊装；吊运易散落材料未使用专用料斗；料斗装载过满。
负例使用标准料斗吊运散料，装载量合规；钢筋绑扎成捆使用专用吊具吊装。
边界吊具类型无法清晰辨认；装载量难以从图像中准确判断。

#11 吊篮作业（更新）

📋 法规依据：JGJ/T 429-2018 §5.8.5；JGJ 202-2010 §5.5.8；JB/T 11699-2013 §5.2.3.7

判定标准
正例吊篮内操作人员超过2人（JGJ 202-2010）；双动力吊篮仅1人操作（JB/T 11699-2013）；吊篮内人员未佩戴安全带或安全绳未固定。
负例吊篮内≤2人且均正确佩戴安全带；按产品说明书要求使用。
边界吊篮内人数难以准确计数（遮挡/角度）；安全绳/带是否固定无法确认。

#12 工地围挡封闭（更新）

📋 法规依据：JGJ 59-2011 §3.2.3

判定标准
正例市区主要路段围挡高度不足2.5m；一般路段围挡高度不足1.8m；围挡破损、倒塌、未连续封闭；围挡明显不稳固或倾斜。
负例围挡高度达标、连续封闭、结构稳固、外观整洁。
边界无法判断围挡实际高度（缺乏参照物）；围挡部分遮挡无法确认完整性。

#9 人员聚集 / #10 车辆违规（待补充）

#5 人员越界、#7 明火检测、#9 人员聚集、#10 车辆违规，以及 #2 反光衣未穿 的详细判定标准，参照上述格式，在标注工作启动前由双方共同确认并编入《标注指导手册》。核心原则不变：

  • 有明确视觉特征 → 正例
  • 明确不存在 → 负例
  • 模糊/遮挡/无法判断 → 边界

#7 明火检测

判定标准
正例施工现场出现非受控明火。包括：露天焚烧垃圾、违规动火作业无消防措施、可见明显火焰。
负例受控动火作业（已审批+灭火器在场+看火人）；电焊弧光（非明火）；阳光/灯光反射；厨房/食堂正常用火。
边界疑似火焰但可能是强光反射；烟雾可见但火源不可见；夜间灯光与火焰难以区分。
⚠ 重要：标注人员在标注时若把握低于90%，应直接标记为"边界"并备注原因，不得强行判定。边界样本的积累是后续难例挖掘和针对性优化的关键输入。

四、输出形式定义

单次检测的输出采用 JSON 格式，每个检测到的隐患作为一个对象：

字段类型必填说明示例

hazard_typeint✓隐患类型编号 1-121
hazard_namestring✓隐患中文名称"安全帽未佩戴"

vlm_resultobjectVLM复核结果见下方
severitystring✓严重级别"major" / "moderate" / "minor"

五、数据集建设方案

5.1 数据采集范围

维度要求
数据来源现有项目已部署摄像头的历史抓拍 + 补充专项采集
场景覆盖覆盖至少3个不同施工阶段（基础/主体/装修）的不同工地
光照条件白天/阴天/黄昏/夜间（含补光）/逆光，每种 >= 10%
天气条件晴天/阴天/雨天，每种 >= 10%
拍摄角度俯视/平视/仰视，不同摄像头安装位置
图像格式JPG/PNG，分辨率 >= 1280×720，建议1920×1080

5.2 数据集数量规划

类别训练集验证集测试集小计（每类）
每类正例（有隐患）≥ 350≥ 75≥ 75≥ 500
每类负例（无该隐患）≥ 150≥ 30≥ 30≥ 210
每类边界样本———≥ 50（不入训练，备查）
12类合计≥ 6,000≥ 1,260≥ 1,260≥ 8,520（+600边界）
说明：单张图片可能同时包含多种隐患类型，每类隐患的计数独立。实际图片总数约为计划数量的 60-70%（因一张图含多个隐患），即约 5,000-6,000 张独立图片。

5.4 标注工具与规范

  • 推荐工具：LabelImg / Label Studio / CVAT（支持 YOLO 格式导出）
  • 标注类型：矩形边界框（Bounding Box）+ 类别标签
  • 标注粒度：每个隐患实例单独标注一个框，不合并相邻的同类别实例
  • 标注原则：框紧密包围目标物体，外扩不超过5px；遮挡超过50%的目标标注为边界样本
  • 一致性检查：每批次标注完成后，随机抽取20%由第二人交叉验证，不一致率 >10% 则整批返工

5.5 质量控制机制

环节检查内容标准不达标处理

六、模型微调技术方案

6.1 YOLO 微调方案

参数配置说明
基础模型YOLO26s-v2.1 (当前生产版本)在现有权重基础上微调，而非从头训练
训练框架Ultralytics YOLO标准 YOLO 训练流程
Epochs100-150根据验证集 loss 早停
Batch Size16-32根据 GPU 显存调整
Image Size640×640保持与当前版本一致
Learning Rate0.001 (初始) → Cosine调度微调降低初始学习率，避免灾难性遗忘
数据增强Mosaic + MixUp + HSV抖动 + 随机翻转提升泛化能力
损失函数CIoU Loss (分类+定位+置信度)标准 YOLO 损失
验证频率每 5 epoch 验证一次监控过拟合
早停策略val/mAP 连续15 epoch无提升防止过拟合
输出微调后的权重文件 (.pt)新版本号命名：YOLO26s-v2.2-ft

6.2 VLM 微调方案

参数配置说明
基础模型Qwen3.6-27B (当前版本)视觉语言大模型
微调方法LoRA (Low-Rank Adaptation)低秩适配，高效微调，不修改原模型权重
LoRA Rankr=16, alpha=32平衡微调效果与效率
训练数据图像+QA对（见 4.3 节）每类 ≥ 200 对，共 ≥ 2,400 对
Epochs3-5LoRA 微调收敛较快
Batch Size2-427B 模型显存受限
Learning Rate2e-5VLM 微调常用学习率范围
优化器AdamW
推理引擎vLLM保持与当前生产一致
输出LoRA 适配器权重不改变基础模型，可动态加载/卸载
⚠ 注意：VLM 微调的核心目标是提升其对施工场景隐患的判断准确性，而非修改其视觉识别能力（视觉编码器冻结）。LoRA 适配器主要作用于模型的注意力层和 FFN 层，引导模型在安全巡检场景下的推理逻辑。
